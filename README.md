# K 线倒计时（Windows 桌面角标）

一个只做一件事的 Windows 小工具：**按你选择的 K 线周期，与系统标准时钟对齐，实时显示当前 K 线还剩多久结束，并在你设定的时间点变色闪烁 / 出声提醒。**

不做行情接入、不下单、不管账户。启动后没有主窗口，只在桌面右下角显示一个可拖动的小角标。

## 下载（不想装 Python 就用这个）

[**KlineCountdown-1.1.0.exe**](https://github.com/zhuijing1/kline-countdown/releases/download/v1.1.0/KlineCountdown-1.1.0.exe)
— 11.1 MB，单文件、免安装，Windows 10/11 64 位双击即用（Python 运行时、Tcl/Tk、VC 运行库都已内置）。

> 下载后如果 SmartScreen 提示"未知发布者"，点「更多信息 → 仍要运行」（没有代码签名证书都会这样）。
> 也可在 [Releases 页面](https://github.com/zhuijing1/kline-countdown/releases) 查看所有版本。

## 一、运行

### 环境要求
- Windows 10 / 11
- Python 3.10 及以上（**只用标准库**，不需要 pip 安装任何依赖）

### 启动方式
| 方式 | 说明 |
| --- | --- |
| 双击 `run.bat` | 推荐。自动寻找 `pythonw`，无控制台窗口 |
| 双击 `dist\K线倒计时.exe` | 打包后的单文件版（免安装、免 Python），同样无控制台 |
| `python main.py` | 调试用，能看到日志输出 |
| 托盘菜单 → 开机启动 | 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，下次开机自动运行 |

> 程序是单实例的：重复启动会静默退出，不会出现两个角标。
> 用 `python main.py` 启动时，如果控制台是这次启动新建的（独占），程序会把它隐藏，
> 免得任务栏多一个命令行图标；如果是从你自己的 cmd/PowerShell 里运行，则不会动你的终端。

### 打包成 exe（发给别人用）
双击 **`build.bat`**（或 `python build.py`），产物：**`dist\K线倒计时.exe`**（约 11 MB）。

把**这一个文件**拷到任何 Windows 10/11 64 位电脑，双击就能用——不需要装 Python，
也不需要额外的运行库（`python313.dll`、`VCRUNTIME140.dll`、Tcl/Tk 都打进去了）。

- 图标统一用 `assets\app.ico` → **exe 文件图标 / 任务栏图标 / 托盘图标三者一致**
- `--windowed` 无控制台窗口；`--onefile` 单文件
- 文件属性里的「描述 / 产品名称 / 原始文件名」都是「K线倒计时」（`version_info.txt`）
- 打包时把 `assets\` 一起带上，运行时优先用随包分发的图标（`core/resources.py`）
- 构建逻辑写在 `build.py` 而不是 `.bat`：cmd 按 GBK 解析批处理，中文名容易乱码

> 首次运行时如果 Windows SmartScreen 提示「未知发布者」，点「更多信息 → 仍要运行」即可
>（单文件 exe 每次启动会解压到临时目录，个别杀软可能误报，属正常现象）。
> 配置文件在 `%APPDATA%\KlineCountdown\config.json`，卸载直接删 exe 即可，不写系统目录。

### 放到桌面
直接把 `dist\K线倒计时.exe` **复制**到桌面即可双击使用（它本身就是免安装的）。
想要标准的「快捷方式」图标，右键这个 exe → **发送到 → 桌面快捷方式**，
由系统生成的 .lnk 最可靠；之后可以删掉桌面上的 exe 副本。

> 不要手工拼 .lnk：Windows 要求里面带 `LinkTargetIDList`（由 Explorer 生成的扩展块），
> 只有 `LinkInfo` 的简化版双击没反应。

### 停止
右键角标 → **退出程序**；或托盘图标右键 → 退出。

## 二、日常操作

### 角标
- 左键拖动可移动位置（设置里可「锁定位置」）
- 双击角标 = 显示/隐藏
- 右键角标 = 全部常用操作（见下）
- 非交易时段显示 `--:--`（文案可改，颜色与交易时段一致），配置有错时显示 `ERR`
- **不占任务栏、不进 Alt+Tab**：角标是桌面挂件（`WS_EX_TOOLWINDOW`），
  任务栏上只有在打开「设置」窗口后才会出现图标

### 右键菜单（角标）
当前周期 / 当前配置用 **✓** 标出，不再单独占一行重复显示：
```
周期                     ← 切换「周期方案」（主周期），整套叠加周期跟着换
  ✓ 5 分钟               ← 对勾 = 当前主周期
    15 分钟
    30 分钟 …
──────────────
配置                     ← 分组标题
  ✓ A 股                 ← 对勾 = 当前配置
    期货（日盘+夜盘）
    全天连续（整点对齐）
──────────────
设置…                     ← 一个入口，里面分「交易时段 / 外观」两页
──────────────
锁定位置   鼠标穿透（Ctrl+Alt+K 可解除）   显示/隐藏角标
──────────────
开机启动   退出程序
```

### 托盘图标右键菜单
周期与配置折叠成两级子菜单，其余是行为开关：
```
周期 ▸  1 / 3 / 5 / 15 / 30 / 60 分钟（当前项带勾）
配置 ▸  A 股 / 期货 / 全天连续（当前项带勾）
──────────────
鼠标穿透（Ctrl+Alt+K）   锁定位置   隐藏/显示角标
──────────────
设置…   退出
```

### 全局快捷键（穿透后也能用）
| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + K` | 开/关鼠标穿透 |
| `Ctrl + Alt + H` | 显示/隐藏角标 |

> **鼠标穿透是什么**：开启后角标对鼠标完全「透明」——点击、右键、拖动都会穿透到下面的窗口，
> 相当于角标变成一块纯显示的小黑板，不会挡住你操作行情软件。
> 代价是它自己也点不中了，所以务必记住 `Ctrl+Alt+K` 这个解药（托盘图标右键里也有同一个开关）。
> 打开前设置页会二次确认，并列出三种解除方式。
切换周期或配置后**立即**按新规则重算，不需要重启，也不需要打开设置窗口。

### 托盘图标
左键单击/双击 = 显示或隐藏角标；右键 = 周期、配置快捷切换。

## 三、周期是怎么算的（重点）

### 与标准时钟对齐
倒计时始终由「当前系统时间 + 配置」重新推导，**不是**从启动时刻开始倒数，也**不是**每秒减一。因此：

- 09:32:15 打开软件、5 分钟周期 → 显示 `02:45`（到 09:35:00）
- 10:07:23 从 5 分钟切到 15 分钟 → 立即显示 `07:37`（到 10:15:00），而不是从 15:00 重新开始
- 休眠唤醒、系统时间被修改、界面卡顿之后，都会在下一次刷新自动回到正确状态

### 两种周期对齐规则（可切换）

| 规则 | 说明 | 典型场景 |
| --- | --- | --- |
| **交易时段起点对齐**（默认） | 以每段交易时段的开始时刻为锚点，向后按周期等分 | 国内多数行情软件。A 股 60 分钟线是 09:30–10:30、10:30–11:30 |
| **整点时钟对齐** | 以自然日 00:00 为锚点等分，边界落在整点/半点 | 24 小时连续交易、按整点切分的图表 |

两种规则在 5/15/30 分钟上结果相同；在 60 分钟等「跨整点」周期上不同，所以做成了配置项而不是写死。

**为什么不能只对周期取模**：取模会忽略交易时段，午休时会把上午最后一根 K 线错误地延伸到下午。本工具把每个交易时段单独切分，**周期绝不跨越非交易时段**。

### 边界细节
- 时段剩余不足一个完整周期时，最后一根 K 线**截断到时段结束**（例：09:00–10:10 配 45 分钟周期 → 09:00、09:45、10:10 三根，最后一根 25 分钟）
- 11:29:00（5 分钟周期）→ 只剩 60 秒，11:30:00 立刻进入「休市间歇」，13:00:00 自动开始下午第一根
- 时段配置重叠、开始晚于结束、周期过短/过长、未选交易日 → 角标显示 `ERR`，设置页红字指出具体原因

## 四、交易时段与周期

设置 → **交易时段** 标签页：

- 支持**多套配置**（新建 / 复制 / 删除 / 设为当前），每套配置独立保存自己的交易时段、周期方案、对齐规则、适用星期
- 一套配置里可以有**多个时段**，例如 A 股 = 上午盘 09:30–11:30 + 下午盘 13:00–15:00，它们属于同一个配置，不需要来回切换
- 每个时段可单独启用/停用
- 交易日按星期勾选（暂不识别法定节假日，见「已知限制」）

内置三套：**A 股**、**期货（日盘+夜盘）**、**全天连续（整点对齐）**，都可随意改。

### 周期方案：主周期 + 叠加周期

一个配置里可以有多套「周期方案」，**每套 = 1 个主周期 + 若干叠加周期**：

```
主周期  [5 分钟 ▾]  ⚙              ← 角标上的数字永远是它
叠加周期  2/10
  [30 分钟 ▾]  ⚙  ✕
  [60 分钟 ▾]  ⚙  ✕
  [+ 添加周期]
```

- **换主周期 = 换一整套方案**：叠加周期列表、每个周期的颜色和提醒节点全都跟着换。
  比如「5 分钟」方案挂了 15/30/60 三个叠加，切到「30 分钟」时看到的是那套方案自己的叠加列表（可能是空的）
- 没配置过的主周期是一张白纸：默认颜色 + 默认节点（60/30/10/3）+ 没有叠加周期，需要自己加
- 叠加周期**必须严格大于主周期**（比主周期小的叠加周期永远不会显示，所以添加时直接过滤掉了），同一套方案内不能重复，最多 10 个
- 主周期可改不可删；叠加周期可增删，不能提升为主周期
- 对齐规则由整配置共用，所有周期都从**该品种的交易时段起点**起算（A 股就是 9:30）

点周期后面的 **⚙** 进入该周期的设置：颜色（数字色 / 背景色 / 透明背景）+ 该周期的提醒节点。

### 多周期接管规则（重点）

叠加周期平时**完全不显示**，只在快收盘时接管角标：

1. **接管窗口**：某个叠加周期的剩余时间 ≤ 主周期长度时，说明它进入了「最后一根主周期 K 线」，
   从这一刻起由它接管。比如 5 分钟主周期 + 30 分钟叠加，接管窗口是每根 30 分钟线的最后 5 分钟
2. **谁赢**：同时有多个周期在窗口里，**周期最大**的那个接管（30 分钟和 60 分钟同时要收盘 → 60 分钟）
3. **其余全静默**：没抢到接管权的周期（包括主周期）的提醒**不显示、也不出声**，
   并且直接记为已触发，不会等接管结束后补响
4. **数字不变**：角标上的倒计时永远是主周期，接管只换颜色/闪烁/声音

举例（5 分钟主周期 + 30 分钟叠加，30 分钟线 10:00–10:30）：

| 时刻 | 显示 |
| --- | --- |
| 10:24:59 | 主周期的颜色，30 分钟还差 301 秒，不接管 |
| 10:25:00 | 30 分钟剩余 300 秒 → 进入接管窗口，换成 30 分钟的颜色，数字仍是 5 分钟的 05:00 |
| 10:29:30 | 30 分钟的 30 秒节点触发，响铃 + 闪烁 |
| 10:29:50 | 5 分钟自己的 10 秒节点被静默，不响也不变色 |
| 10:30:00 | 两根 K 线同时结束，回到主周期 |

> 注意：时段起点对齐下，60 分钟线是 09:30–10:30 / 10:30–11:30，和 30 分钟线只在 :30 / 整点这些
> 边界上同时结束。所以 30 + 60 都开时，30 分钟的提醒只在「不是 60 分钟末根」的那些 30 分钟线上生效。

## 五、提醒

提醒节点挂在**每个周期**上，在周期齿轮里编辑（不再有单独的提醒页）。

默认 60 / 30 / 10 / 3 秒四个节点，可自由增删改。每个节点可独立设置：
- 剩余多少秒触发（**必须严格小于主周期长度**，输入框已按上限锁死）
- 数字颜色、背景颜色、闪烁色
- 是否闪烁、闪烁方式（颜色对调 / 闪烁色脉冲）、频率（Hz）、持续时长（0 = 到本根 K 线结束）
- 是否播放声音、音源（4 个内置提示音或本地 wav/mp3/wma）、音量
- **重复 / 每次间隔**：重复 = 连着响几下，间隔 = 每下之间停多久。
  「重复 3 次 + 每次间隔 0.5 秒」= 响 → 停 0.5s → 响 → 停 0.5s → 响
- 试听按钮

另外：
- **一键关闭所有声音与闪烁**（交易时段页底部）：静音后连闪烁样式一起停用，跨所有周期
- 去重规则：同一根 K 线的同一个节点**只触发一次**；换 K 线自动重置；启动、唤醒、改设置、切周期都不会补响历史节点；系统时钟被回拨到上一根 K 线也不会重复响
- 去重按「周期 + 节点 id + 剩余秒数」：不同周期的同名节点互不干扰；**把节点的剩余秒数改了，等于换了个新节点**，会在新阈值处再响一次（调参数测试时不会「只闪不响」）
- 一次刷新最多只响「最贴身」的那个节点，避免启动瞬间连响四声

## 六、外观

设置 → **外观** 标签页，全部改动即时生效并自动保存。这里只放**跨品种、跨周期共享**的物理属性：

| 行 | 内容 |
| --- | --- |
| 字体 | 字族（默认 Bahnschrift，笔画干净）+ 字重。列表已过滤掉 `@宋体` 这类竖排变体 |
| 字号 | **滑块**，10–96，拖动时角标实时变化 |
| 透明度 | 整窗 alpha，0.1–1.0 |
| 空闲文案 | 非交易时段显示的文字（颜色沿用主周期的颜色） |
| 窗口行为 | 置顶 / 鼠标穿透 / 锁定位置 / 重置位置 |

**高级（一般不用改）**：内边距、固定宽高（0 = 按字号自动）、圆角半径（0 = 直角）。

> 数字色 / 背景色 / 透明背景**不在这里**——它们在每个周期自己的 ⚙ 里，
> 这样 5 分钟主周期和 30 分钟接管态可以是两套完全不同的配色。

> **为什么没有描边了**：以前的透明是「颜色键」——拿一个颜色当全透明，
> 文字抗锯齿的边缘像素既不是纯字色也不是键色，被原样画到屏幕上就成了黑边/毛刺，
> 只能靠描边去盖。现在改成**逐像素 alpha**（`UpdateLayeredWindow`），
> 边缘是真正的半透明像素，和任何壁纸自然融合，描边这层补丁就不需要了。
> 实测白底上零黑边（最暗像素就是文字色本身）。

### 想要「透明背景、只有数字」怎么做
1. 交易时段页 → 点主周期后面的 **⚙**
2. 勾选 **透明背景（只显示数字，不画色块）**
3. 「数字色」按壁纸选：深色壁纸用亮色（白 / 黄 / 青），浅色壁纸用深色（黑 / 深蓝）
4. 不需要描边；边缘自带半透明过渡
5. 圆角此时不起作用（没有底块了）

### 想要「只有数字闪，底色不动」怎么做
提醒节点里把 **闪烁方式** 选为 **仅文字闪烁**（默认就是它）。
另一种「整块闪烁（背景变色）」会让整块底色在两种颜色间跳，适合需要强提醒的场合。

> 鼠标穿透打开后角标点不到，用**托盘图标右键 → 鼠标穿透**，或按 **Ctrl+Alt+K** 关掉。
> 如果托盘图标也找不到，退出程序后把 `config.json` 里的 `click_through` 改成 `false` 再启动。

## 七、配置文件

位置：`%APPDATA%\KlineCountdown\config.json`（便携/测试可用环境变量 `KLCD_CONFIG` 指定）

- 原子写入（临时文件 + 替换），异常断电不会留下半截文件
- 文件损坏会自动备份为 `config.corrupt-<时间戳>.json` 并回落默认配置
- 带 `schema_version`（当前 **v2**）；v1 的旧配置会自动迁移：
  原来的「单个周期 + 提醒 + 全局颜色」会被包成第一套方案的第一个周期，颜色也一并搬过去
- 图标资源生成在 `%LOCALAPPDATA%\KlineCountdown\icons\`

```
├─ ui/
│  ├─ badge.py             桌面角标窗口（无边框/置顶/透明/穿透/拖动）
│  ├─ settings.py          设置窗口（交易时段+周期方案 / 外观 / 周期齿轮对话框）
│  └─ theme.py             颜色选择、数字输入、滑杆等小控件
├─ tests/                  单元测试 + 集成测试 + 渲染测试 + 多周期测试（94 项）
├─ tools/                  截图/抓图辅助脚本（开发用，capture_window.py 可按窗口句柄抓图）
└─ docs/                   截图与文档
```

分层原则：`core/` 不 import tkinter，所有时间计算都是「输入时间 → 输出状态」的纯函数，因此可以脱离界面精确测试。

## 十、已知限制与设计假设

1. **不识别法定节假日**：只按星期判断交易日。遇到长假需要手动停用配置或关闭程序。
2. **不自动获取交易日历**：这是「不接行情/不做市场数据」的直接结果。
3. **透明度是整窗透明度**，不是「背景透明但文字不透明」。若需要背景更透而文字清晰，可把背景色设得更深、文字色设得更亮。
4. **圆角模式使用 Windows 颜色键透明**（`#010202`），在极少数主题下文字边缘可能有轻微杂色；把圆角设为 0 可完全避免。
5. **mp3 等格式的音量控制是「尽力而为」**（依赖系统 MCI 解码器支持），wav 与内置音是精确的音量缩放。
6. **多显示器**：位置会被钳制在虚拟桌面内，DPI 缩放变化后位置按 Tk 坐标保存；跨不同 DPI 的显示器拖动时可能需要微调。
7. 周期对齐默认「交易时段起点对齐」，这与国内多数行情软件一致；若你的图表按整点切分，请在配置里切换为「整点时钟对齐」。
